# MathArena

MathArena is a Roblox multiplayer math game.

## Development

This project uses Roblox Studio, Rojo, VS Code, Git, and GitHub.

## Project Structure

- `src/ServerScriptService` — server-side systems
- `src/ReplicatedStorage` — shared code
- `src/StarterGui` — user interfaces
- `src/StarterPlayer` — client-side scripts
- `src/Workspace` — game world
